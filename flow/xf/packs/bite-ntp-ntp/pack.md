# Pack: bite-ntp-ntp

Interface `NTP` of the first-bite dictionary `ntp`, version 1.0.0, generated by
`tools/bite2pack/bite2pack.py`. Do not edit `pack.def`, `model/ntp.def` or the vectors by hand; change the
dictionary or the generator and run it again.

## Message convention

A message is the payload first-bite decodes: the transport payload of one packet. A field
`[start, stop)` is `0:<start>:<stop - start>`; the message type is bits [5, 8).

`wire bits`, `word_bytes 1`, `bit_order msb` (the dictionary's `msb0`). Input and output are hex text.
Every field is `optional`: a payload cut short decodes up to the cut, as in first-bite.

### Messages

- `NTP control message` is named by `message_type` and has no message file. Its kind has a `when` and no field, as first-bite identifies it and decodes nothing.

## Shared keys

None. The bindings file names no message of this interface, so a conversion to another format carries
only what the caller supplies as context.

## Scale arithmetic

first-bite rounds `raw * scale + offset` to the decimal places `scale` and `offset` are written with. The engine
computes `raw * num / den`, then `+ offset`. The generator compares the two doubles:

| Transform | Bits | Raw values compared | Doubles that differ | Largest difference |
|---|---|---|---|---|
| `uscale:1/65536` | 32 | 65541 raw values (edges and a fixed pseudo-random sample) | 0 | 0 |
| `uscale:1/4294967296` | 32 | 65541 raw values (edges and a fixed pseudo-random sample) | 0 | 0 |

## What the pack does not state

- first-bite passes a text byte outside 0x20 to 0x7E; the engine refuses the message.
- The dictionary's `port`, `message_length` range, `declared_bits`, `icd_numbering`, `source` and `note` keys have no directive; `port` is how first-bite picks the interface.
